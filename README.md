# kod-link-dify

`kod-link-dify` 是一个用于 **可道云 (KodExplorer)** 与 **Dify** API 交互的 Python 客户端库。  
它封装了登录、获取 token、以及常用 API 请求，方便快速集成到业务中。

---

## 功能特性

- 🔑 简单登录并获取 token  
- ⚡ 便捷调用 KodExplorer API  
- 🧩 支持在 Dify 场景中扩展对接  
- 🛠️ 可扩展的模块化结构（`auth`, `api`, `config`）
